# Haya Job Autopilot v3.1 development

v3.0.0 remains the immutable known-good release. Development continues only on `v3.1-dev` until Windows CI and controlled live-mail QA are complete.

## First tranche

- canonical URL deduplication that strips common tracking parameters while preserving vacancy identifiers
- title/company/host fingerprints to reduce duplicate alerts across differently tracked links
- setup-readiness reporting without exposing credentials
- local diagnostics endpoint and dashboard panel
- explicit Yahoo IMAP connection test
- run telemetry: duration, alert-message count, newly discovered jobs, run reason and applications today
- clearer Ready / Needs Haya / Applied / Filtered / Rejected queues
- track/status/score/risk/sort filters
- routine manager errors remain in the status panel instead of spawning modal error popups
- detailed manual-search errors returned to the manager
- strict start-date format validation

## Release gate

Do not publish v3.1.0 as a release until:

1. Windows hosted unit tests pass.
2. Windows hidden-agent runtime smoke passes.
3. Dashboard diagnostics and safety gates pass.
4. GUI remains alive under the hosted smoke test.
5. A controlled real Yahoo connection test succeeds on Haya's Windows account.
6. Monitor Only discovers at least one genuine job alert without duplicate inflation.
