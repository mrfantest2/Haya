# v3.1 Web App Direction

v3.0.0 remains the immutable production baseline.

v3.1 changes the primary Windows experience from a three-column native manager into a guided local web application.

## Chosen shell

- Native Go background agent remains the source of truth.
- The visible interface is served locally from `127.0.0.1:8787`.
- The normal EXE launches the local UI in Microsoft Edge app mode (`--app=`), producing an app-style window without normal browser chrome.
- If Edge app mode is unavailable, the UI falls back to the default browser.
- The existing Win32 manager remains available only as `--native-manager` for repair/fallback.

This keeps the stabilization path dependency-light while making the frontend ready for a later embedded WebView2 host without another UI rewrite.

## Simplified UX

Primary navigation: Home, Jobs, Profile & CV, Settings.

A fresh install is usable immediately with manual vacancy URLs. Yahoo is optional and only needed for Yahoo job-alert discovery or permitted email sending. Hungary work eligibility, sponsorship, start date and salary are optional verified application answers and do not block startup.
