# Poker Vision v0.2.7 — Release Notes

## English
Poker Vision is ready for its first Google Play preflight release.

What's included:
- Tap any of the 7 card slots to select the exact position
- Replace or remove an existing selected card
- Automatic move to the next empty slot
- Camera-assisted playing-card scanning
- Manual card selection with native card-face visuals
- Complete 52-card guide
- Poker hand ranking guide
- Offline Texas Hold'em equity estimates against 1–5 random opponents
- Arabic and English interface
- New Poker Vision launcher/store icon
- Android 16 / API 36 target

No accounts, ads, subscriptions, in-app purchases, or real-money wagering.
